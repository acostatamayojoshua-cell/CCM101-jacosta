# Security Audit Report

## Principle of Least Privilege (PoLP)
This principle means a user should only have the exact access they need to finish their work, nothing more. It matters in cloud accounts because if someone’s account gets hacked, the damage will be smaller since they don’t have extra permissions.

## Attack Surface
The attack surface is all the possible ways an attacker can try to break into a system. On a virtual machine, this usually means open ports, services running in the background, or weak settings that can be abused.

## Default Deny Policy
A Default Deny Policy means blocking everything first, then only opening what is really needed. This is safer because instead of chasing every hacker, you just allow the specific traffic you trust, which makes the server harder to attack.
