# Mission Reflection

## A host-based firewall protects a server by controlling traffic directly on the machine. Even if someone breaks through the physical network, the firewall rules on the server itself can still block unwanted access. This adds another layer of defense that makes the system harder to attack.

## Managing open ports is very important because every open port is like a door into the server. The more doors you leave open, the more chances attackers have to get inside. By closing everything and only opening what is needed, you reduce the attack surface and make the server safer.

## In a real company, leaving a database port like 3306 open to the public internet is very risky. Databases often contain sensitive information, and if hackers can connect directly, they might steal or damage data. That is why database ports should only be accessible inside the private network or through secure connections.

## Doing this mission made me realize how easy it is for a server to be compromised if you don’t set up security right away. Just leaving the firewall off for a short time can expose the system to attacks. It showed me that security is not something you add later, but something you must do from the start.
