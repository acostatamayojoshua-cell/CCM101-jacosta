

# Final Reflection — Mission 10: The Enterprise Cloud Architect

As a group, we learned how virtualization, containerization, networking, security, and automation work together in an enterprise cloud environment.

We used VirtualBox to run Ubuntu Server and installed Docker and Docker Compose to deploy WordPress and MariaDB as connected containers. We also configured persistent Docker volumes to help preserve application and database data.

During this activity, we learned how to configure UFW firewall rules to deny incoming connections by default while allowing the necessary ports for SSH and WordPress access. We also created a Bash automation script and configured a Cron job to monitor Docker container status automatically.

One of the challenges our group encountered was resolving Docker permission issues and ensuring that WordPress could be accessed through a web browser. By following the setup instructions, checking our configurations, and working together, we were able to get the application running.

Overall, this laboratory activity improved our understanding of Linux server administration, virtualization, container management, networking, firewall security, and automation. It also taught us the importance of teamwork, troubleshooting, and proper documentation when building and maintaining an enterprise cloud environment.
