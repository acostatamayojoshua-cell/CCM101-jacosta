1. Mission Overview
This mission focuses on learning basic Linux command-line operations using Killercoda as an interactive browser-based terminal environment. It also aims to document and save all executed commands and outputs to a GitHub repository for verifiability and progress tracking.

2. Objectives

Familiarize with basic navigation and file manipulation in the Linux terminal.

Create custom directories and text files for hands-on execution.

Track and store terminal history.

Create and commit a lab report/documentation to a GitHub repository.

3. Activities Performed

Logged into Killercoda and opened an Ubuntu/Linux playground terminal.

Verified the active user, hostname, and current working directory.

Created a new folder named linux-basics-lab and navigated inside it.

Generated a text file (lab_report.txt) and added notes using command-line tools.

Inspected the contents of the created file and listed the directory structure.

Extracted the list of all executed commands from the terminal history.

Created a new repository on GitHub, initialized Git in the local folder, and pushed the documentation and history logs.

4. Linux Commands Used

whoami – Displays the current active user account (e.g., ubuntu).

hostname – Displays the name of the system/node running on Killercoda.

pwd – (Print Working Directory) Shows the full path of the current directory.

ls / ls -la – Lists files and directories within the current folder (including hidden files).

mkdir – Creates a new directory/folder (mkdir linux-basics-lab).

cd – (Change Directory) Navigates into a specified folder (cd linux-basics-lab).

touch – Creates a new blank file (touch lab_report.txt).

cat – Displays the full content of a text file in the terminal.

history – Outputs the complete list of commands executed during the session.

5. Skills Learned

Command-Line Proficiency: Learned how to navigate and manipulate files and directories strictly using the terminal without a Graphical User Interface (GUI).

Hands-on Cloud Environment Usage: Gained experience practicing Linux and DevOps fundamentals through browser-based interactive labs on Killercoda.

Version Control & Documentation: Mastered integrating Linux workflows with GitHub using core Git commands (git init, git add, git commit, git push) to save and submit lab outputs.
