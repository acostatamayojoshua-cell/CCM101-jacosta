1. Which cloud provider offers the broadest range of services? Explain your answer. 
   Amazon Web Services (AWS) offers the broadest range of services because it was the first major public cloud platform to market, giving it a head start in global infrastructure deployment. As a result, AWS has built the largest and most diverse service ecosystem, ranging from standard compute instances to specialized tools for satellite communication and IoT management.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
  I would recommend Microsoft Azure for an organization heavily invested in Microsoft software. Azure provides seamless, native integration with enterprise tools    like Microsoft Entra ID, Active Directory, Windows Server, and Office 365. Additionally, organizations can often leverage existing licensing agreements through hybrid cost savings programs.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and
Kubernetes services? 
Google Cloud Platform (GCP) is widely recognized for its industry leadership in AI, ML, and Kubernetes. GCP natively offers specialized infrastructure optimized for deep learning models—such as Tensor Processing Units (TPUs)—and holds a strong advantage in container management because Kubernetes was originally developed inside Google.

4. What similarities did you observe among the three cloud providers?
   All three cloud providers share core functional capabilities by offering virtualized compute instances, scalable object and block storage, virtual private networking, and centralized identity access control. Furthermore, they all operate under a pay-as-you-go financial model that eliminates upfront hardware investment while providing high availability and enterprise-grade security controls.
