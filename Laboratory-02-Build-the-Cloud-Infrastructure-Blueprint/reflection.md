Which cloud infrastructure component do you think is the most important? Why? 
 I think virtual networking is the most critical cloud infrastructure component. While compute and storage provide the resources to process and hold data, networking defines the security boundaries, routes traffic, and enables seamless communication between isolated services. Without a well-designed network, cloud resources cannot safely interact with each other or serve end users reliably.

 How does Linux support cloud computing?
  Linux serves as the primary backbone of cloud computing due to its stability, open-source flexibility, lightweight resource footprint, and strong command-line automation capabilities. Most virtual machines, container runtime environments, and cloud management tools run natively on Linux distributions, allowing cloud platforms to scale efficiently across massive server fleets.
