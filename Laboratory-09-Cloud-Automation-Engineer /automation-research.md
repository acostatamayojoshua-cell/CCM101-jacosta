# Bash Script: 
 A bash script is basically a text file filled with a list of commands that the Linux terminal can run step-by-step. At the very top, it uses a shebang line (#!/bin/bash) to tell the system which interpreter needs to read and execute the file.
# Variables: 
Variables act like labeled storage boxes where you can save specific values, such as a folder path. Programmers use them so they don't have to keep typing the exact same path over and over, which makes updating the code much easier.
# Cron Job:
A cron job is a built-in time scheduler in Linux that runs your scripts or commands automatically at set dates and times. It is super important for cloud operations because it lets systems handle routine chores like backups on their own without needing someone to manually trigger them.
